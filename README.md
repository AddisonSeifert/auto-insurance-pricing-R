# auto-insurance-pricing-R
# Auto Insurance Pricing Analysis in R
This project uses simulated data for 3,000 auto-insurance policies to demonstrate a basic actuarial pricing analysis.
## Objective
Analyze how expected insurance costs vary by age group, territory, and vehicle type.
## Methods
The R script simulates policy characteristics, claim counts, and claim amounts. It then calculates claim frequency, claim severity, pure premium, and indicated premium.
## Key findings
- Young drivers had the highest indicated premium among age groups.
- Urban territories had the highest indicated premium among territories.
- SUVs had a higher indicated premium than sedans because they had higher simulated claim frequency and severity.
## Important note
This project uses simulated data for educational purposes; it is not based on private insurer data.
